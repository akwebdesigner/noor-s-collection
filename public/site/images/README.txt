To use your own photos:
1. Add files here, e.g. lawn-02.jpg, pret-03.jpg (recommended 900 x 1200 px, JPG, under 200 KB).
2. Open script.js and change the "image" (and "images" array) value of any product
   to "./images/your-file.jpg".
